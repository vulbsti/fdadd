4. After preview migration/scheduler setup, verify the preview source SHA, worker registration, protected sweeper authorization, one real authenticated recovery loop, and sanitized receipts. Do not promote to production or mutate the two historical connected runs on local evidence.

Architecture assessment: this is not a narrow request-only patch. The transactional outbox, service-only store contract, Workflow self-fence, typed verifier result, canonical question identity, and deployed sweeper boundary are reusable by the P2 job/revision authority. It still does not create the v3 person revision authority, publication fencing, astrology-off guarantee, Atros fault proof, or final approved UI. P1 remains open until the explicit browser recovery/Atros/deployed-sweeper gates pass.
