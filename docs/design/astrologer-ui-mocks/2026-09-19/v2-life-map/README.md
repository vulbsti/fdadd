# Life understanding — revised profile concepts

Four ImageGen mockups grounded in reviewed personal conversations. This approved direction supersedes the first profile mockup in the parent folder. It preserves the Chat / Profile structure and replaces generic personality copy with explorable episodes, meaning changes, patterns with exceptions, and conditional future paths.

The user accepted this visual direction. See the [execution specification package](../../../../architecture/person-model-v3/README.md) for the backend and interaction contracts needed to implement it.

## Files

- [01-life-map.png](01-life-map.png): formative events, a dated present, and possible next paths.
- [02-how-you-think.png](02-how-you-think.png): productive solitude versus prolonged isolation, with a working explanation and a question that can revise it.
- [03-guided-chat.png](03-guided-chat.png): opening that connection in chat with relevant context already present.
- [04-meaning-change.png](04-meaning-change.png): how mortality and identity questions changed a mission, without inventing the unresolved meaning.
- [PROMPTS.md](PROMPTS.md): complete generation and refinement prompts.

All four images were generated with the built-in ImageGen tool. The overview received one image edit to correct chronology, remove generic astrological prose, and remove decorative photographs. The original generated files remain in the Codex generated-images directory.

## Interpretation and review

These are visual design concepts, not implemented screens or verified forecasts. Their biographical examples are an explicitly dated September 2026 snapshot. The product requirements take precedence over illustrative image text. The reviewed source passages and their attribution are listed in the specification.

Each image was visually inspected for readable copy, recognizable personal connections, and a route into further conversation. Production implementation should unify typography across the four views. The fourth image places quotation marks around a paraphrase about admired scientists; production copy should display that sentence as a paraphrase, reserving quotation marks for the user's exact words. No synthetic return-to-people loop should be stored as an established fact: it is a pattern to explore.
