# Personal context

Read `manifest.json` for current authority versions and `person/profile.md` for
the accepted brief. These are entry points, not the complete person. Search
`person/sources/` and `person/structured/` (grep, find and read all work here)
for support and counterexamples, and read full relevant spans before asserting
a fact. Old assistant text is not independent evidence.

Earlier work for this person persists between messages under `work/`,
`outputs/` and `astrology/calculations/`. Check it before redoing analysis.

Save useful outputs as files under `work/` or `outputs/`. Put proposed memory
updates in `proposals/<short-name>.md` with the source IDs (the file names in
`person/sources/`) that support them, and state uncertainty. Proposals are
queued for review; only the publication service accepts a new personal-model
revision, and editing `person/` files changes nothing durable.
