# Precise astrology calculations

Use Atros, not mental arithmetic, for dated chart/dasha claims. For a requested
year, call atros_timeline with that year's date range and the needed period
level. Read the complete relevant records, including transitions. Current dasha
and birth balance are not a full dated timeline. Outputs are saved under
astrology/calculations/ and can be searched/read again. Ask for birth details
only when the capability state reports them missing. Never change consent.
